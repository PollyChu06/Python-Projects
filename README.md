# Beginner Python Projects
This repository contains beginner-level projects developed using Python and the VS Code editor. These projects are designed to help learn and practice basic Python programming skills.
### Projects Included:
- Converter: A simple tool to convert Roman numerals to standard numbers.

- GIF Maker: A program to create GIFs from a series of images.

- Guess_a_Number: A number guessing game where the player tries to guess a randomly generated number.

- QRcode Maker: A tool to generate QR codes from text input.
